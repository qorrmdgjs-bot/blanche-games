# Blanche Studio games (static PWA hosting)

Static web builds of **김밥 지켜! / Gimbap Guardians** and **칼퇴 슛 / Clock-Out Toss**, packaged as installable PWAs for the Microsoft Store.

- `gimbap-guardians/` — same build as the live itch.io version (upload 20814522), plus manifest, service worker and icons.
- `clock-out-toss/` — standalone web build without any store SDK, plus manifest, service worker and icons.
- `privacy/` — privacy policy (no personal data collected).

All art and sound made for this game; AI tools helped along the way.
